UNIVERSAL HEADER — HOW TO EDIT
================================

All 15 pages now use:
  shared-header.js  — the header text and navigation links
  shared-header.css — the header design and teal background

To change the navigation or site title:
  Edit shared-header.js once.

To change colours, font sizes, or header spacing:
  Edit shared-header.css once.

Keep both files in the same folder as all the HTML pages.
Open index.html to preview. The JavaScript works from a local folder.

Do not delete shared-header.js or shared-header.css.
