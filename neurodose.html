Could Living Neural Networks Transform Preclinical Drug Testing?

A proposed closed-loop organoid intelligence framework for Dravet syndrome.

Hypothetical project. No NeuroDose experiments have been performed.

01 / Research question

Can pharmacological treatment restore adaptive learning in human neural networks modelling Dravet syndrome?

Hypothesis: SCN1A-associated changes in neuronal activity may affect performance in a closed-loop task. A suitable treatment might improve adaptive performance while preserving physiological network activity.

Aim: Compare network activity and task-related adaptation in healthy control, Dravet, and drug-treated Dravet neural models.

Project status: Hypothetical research proposal. No NeuroDose biological experiments have been performed.

02 / Why Dravet syndrome?

Dravet syndrome is a developmental and epileptic encephalopathy frequently associated with pathogenic variants in SCN1A, which encodes the NaV1.1 sodium-channel subunit.

It is a useful candidate because human iPSC-derived Dravet models, electrophysiological studies, and pharmacological studies already exist. These provide a starting point for selecting disease-relevant measurements and treatment conditions.

However, a reproducible learning deficit in a Dravet organoid has not been established for our proposed task. Demonstrating that difference would be part of the research.

04 / NeuroMaze: how the game communicates with the HD-MEA

Try the game. This one-level Flash-era maze uses only UP and RIGHT. Each keypress stands in for a command that could eventually be decoded from neuronal activity.

Playable interface demonstration only. The game is not connected to real neurons or an HD-MEA.

For its first phase, NeuroMaze takes inspiration from the infamous Scary Maze Game of the early 2000s. A future, more ambitious extension could explore Counter-Strike 1.6 (2003), with a much richer exchange of information between the game and the neuronal network.

Unlike NeuroMaze's simple UP and RIGHT commands, a first-person game would need to communicate events such as an enemy appearing on the left, incoming damage, or an available escape route. A software encoder could translate these game observations into distinct patterns of electrical stimulation delivered through the HD-MEA. Recorded neuronal responses could then be decoded into actions such as turning, moving, or shooting.

Where PPO could fit: Proximal Policy Optimization is an artificial reinforcement-learning algorithm that improves a software controller through feedback. In this hypothetical extension, PPO could explore how different electrode stimulation patterns influence the network's responses, gradually learning which patterns are more likely to produce useful decoded actions in particular game situations. For example, when an enemy approaches from the right, it might learn a stimulation strategy that makes a RIGHT-turn response more likely. Success or failure in the game would provide the controller's numerical training signal.

This would be a hybrid biological–AI game controller, not direct evidence that neurons had learned the game. The primary NeuroDose experiment therefore retains fixed stimulation and decoding rules to investigate biological adaptation separately from software optimization.

From the maze to the neurons — and back

The neurons do not see the maze. Software converts a task cue into electrical stimulation through selected HD-MEA electrodes, records the network's evoked spikes, then uses a fixed decoder to choose UP or RIGHT.

01 / GAMEMaze state

Read cursor position and select the next cue.

02 / STIMULATEHD-MEA electrodes

03 / RECORDLiving neurons

Capture extracellular spikes after stimulation artifacts clear.

04 / DECODESpikes → UP or RIGHT

Use predefined recording groups and an unchanged decoding rule.

05 / MOVECursor advances

Move one step; a wall blocks an invalid move.

06 / FEEDBACKOutcome → stimulation

Deliver predefined outcome-dependent feedback, then repeat.

The closed loop: maze cue → HD-MEA stimulation → neuronal spikes → fixed software decoder → maze movement → feedback → next cue.

What information would the HD-MEA receive?

Game informationProposed interface
Cue A or cue BDifferent stimulation electrode groups or validated pulse patterns. Pilot recordings must show distinguishable neural responses.
Neuronal decisionArtifact-cleaned spike activity in two predefined recording populations becomes UP or RIGHT. The computer does the translation.
Valid move or wallPredefined outcome-contingent feedback patterns. We cannot assume a pattern is intrinsically rewarding or punishing.
FinishLog completion and optionally deliver a terminal cue; completion alone is not proof of learning.

Important limitation

This maze has a fixed route: UP, then RIGHT. It is useful for testing the interface but cannot by itself demonstrate learning: a biased network might complete it without adapting. A proper assay would require varying cues or contingencies, stable decoding, acquisition and retention measures, and contingent-versus-yoked feedback controls. Electrical pulse parameters and recording windows would be calibrated for the actual HD-MEA and cell model.

05 / 2D development and 3D validation

2D neuronal networks: a practical first platform for developing electrode stimulation, decoding, and feedback. Electrode contact and network access are generally easier to control.

3D organoids: the proposed disease-model validation platform. They provide additional tissue organization, but introduce variability in maturation, electrode access, and drug penetration.

The proposed experiment should select cultures based on functional readiness, not age alone: stable activity, reproducible evoked responses, viability, and consistent task performance.

06 / Pharmacological experiment

Leading candidate: fenfluramine, because it is relevant to Dravet syndrome and has been investigated in human disease-model research. Valproate and cannabidiol are possible comparators.

StageProposed measurement
Before exposureSpontaneous and evoked MEA activity; baseline task performance.
Acute responseDrug-associated changes in excitability and network activity at a literature-supported interval.
Follow-upRepeat task and retention tests; viability and sustained network function.

Concentrations: to be selected from primary in-vitro evidence. Clinical doses in milligrams cannot simply be converted into organoid-bath concentrations. Exposure time, protein binding, penetration, and carryover also matter.

Drug exposure must not be interpreted as a rescue merely because bursting decreases; widespread neuronal silencing would be a competing explanation.

07 / What we would analyse

  • Mean firing rate, burst rate, synchrony, and evoked responses.
  • Task success, learning curve, reaction time, and retention.
  • Differences between healthy, Dravet, vehicle-treated, and drug-treated groups.
  • Viability and evidence of nonspecific suppression.

Distinguishing biological learning from software-driven performance

The NeuroDose framework proposes a comparison between closed-loop and open-loop stimulation to investigate whether neuronal adaptation depends on the relationship between network activity and subsequent feedback. In the closed-loop condition, electrical feedback is determined by the network’s decoded response and its outcome in NeuroMaze. In the open-loop condition, stimulation follows a predefined sequence independently of neuronal activity. A yoked-feedback condition would reproduce stimulation sequences generated during closed-loop experiments without preserving their relationship to the receiving network’s responses.

Differences in task acquisition and retention between these conditions could provide evidence for feedback-dependent adaptation. A fixed neural decoder would further distinguish changes in the biological network from improvements introduced by software recalibration.

08 / Computational framework

NeuroDose proposes a closed-loop interface in which HD-MEA recordings are translated into movement commands and game outcomes determine subsequent electrical stimulation. Existing open-source electrophysiology tools and published biological-computing experiments provide complementary starting points for the proposed architecture. None constitutes an established NeuroDose learning assay.

Neural decoding / From spikes to UP and RIGHT

Cortical Labs’ CL1 API documentation and example notebooks illustrate programmatic access to neuronal recordings, live data streams and stimulation commands. These examples demonstrate how a software environment can interact with an electrophysiological system, although the CL1 interface is not interchangeable with an HD-MEA driver.

For NeuroMaze, two predefined populations of recording electrodes would be associated with the UP and RIGHT outputs. Following each electrical cue, a fixed decoding rule would compare their artifact-cleaned, baseline-normalized responses within a defined time window. The stronger eligible response would determine a single movement command. The electrode populations and decoder thresholds would be established during calibration and held constant during learning experiments, separating biological adaptation from software retraining.

Closed-loop feedback / From game outcomes to stimulation

Kagan et al. (2022), DishBrain provides an experimental precedent for linking a virtual game environment to living neuronal cultures through electrical stimulation and extracellular recordings. Its use of outcome-dependent feedback informs the proposed NeuroMaze loop: the game distinguishes valid movement, collision and completion, and each outcome selects a calibrated stimulation condition.

These outcomes are software-defined; the corresponding electrical patterns cannot be assumed to function as biological reward or punishment. Their effect on future network responses would be tested against matched, noncontingent feedback. The Cortical Labs CL1 SDK and simulator offers an additional reference for experimenting with the software-side interface, rather than evidence of learning in NeuroDose cultures.

Learning analysis / From repeated decisions to a measurable phenotype

The proposed learning endpoint is a change in the network’s cue-dependent decisions over repeated trials, assessed with an unchanged decoder. Acquisition curves would describe the evolution of task performance; retention tests would examine whether changes persist without ongoing training feedback. Contingent-feedback and yoked-replay conditions would help distinguish experience-dependent adaptation from stimulation exposure, spontaneous drift and changes in overall excitability.

SpikeInterface provides open-source tools for extracellular recording analysis, while MEArec generates simulated extracellular recordings useful for evaluating a decoder before biological experiments. Simulated spike trains could illustrate the analysis workflow, but would not be presented as evidence that healthy, Dravet or drug-treated networks have learned.

Within the proposed Dravet model, this framework would allow learning-related outcomes to be evaluated alongside conventional MEA features such as firing rate, bursting and stimulus responsiveness. A drug-associated improvement in maze performance would be interpreted as a candidate functional rescue only if it could not be explained by altered baseline activity or decoding artifacts.
